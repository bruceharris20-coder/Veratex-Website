# Veratex Corporate Website — Phase 4 Final

A responsive static website built with HTML, CSS, and JavaScript.

## Included
- Veratex-branded home, opportunity, solutions, technology, industries, leadership, insights, and contact pages
- Veratex surveillance-camera treatment
- Leadership portraits aligned side-by-side in black suit jackets, white shirts, and no ties
- Responsive navigation and mobile layouts
- Pilot discussion contact form
- No Cordis or Unity branding

## Preview
Open `index.html` in a browser.

## Deployment
The folder can be published to Firebase Hosting, GitHub Pages, Netlify, Vercel, or a standard web host.
